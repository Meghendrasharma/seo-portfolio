How I audit pages that lost rankings after a core update

A step-by-step process: GSC comparison, live SERP check, keyword gaps, internal links and technical checks.

1. Confirm the drop with Search Console

Compare the 28 days before and after the update, page by page. Note clicks, impressions and average position, and separate pages that lost impressions (indexing or relevance) from pages that only lost clicks (CTR or SERP features).

2. Check the live Google SERP manually

Search the main keyword on Google.de with a clean session. Which page types rank now: service pages, directories, guides? If the intent changed, the page has to change with it.

3. Find keyword and content gaps

List the terms the top 5 pages cover that yours does not, for example price keywords like “kosten umzug berlin”. Add them where they answer a real question.

4. Technical and internal links

Check indexability, canonical, H1, orphan status and internal links pointing to the page. On one project, 15 pages had no internal links at all.

5. Prioritise and measure

Fix the highest-traffic page first, request indexing, and track weekly. Keep a log so you know which change moved what.
