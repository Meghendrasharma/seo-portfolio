Shopify SEO: when every colour is its own product

How 162 duplicate product pages split rankings, and how to merge them safely with redirects.

The problem

When each colour or size is a separate product, Google sees many near-identical pages. None of them builds enough strength to rank.

The fix

Keep one main product with variants, set the old products to draft, and import a 301 redirect file (old URL → main product). Then resubmit the sitemap.

Check afterwards

Open a few old URLs to confirm the redirect, and watch Search Console for the old URLs dropping out of the index.
